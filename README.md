# NOTEBIT — متجر إلكتروني للابتوبات (Django)

متجر إلكتروني كامل مخصص لبيع اللابتوبات، مبني بـ Django. يدعم فلترة متقدمة حسب المواصفات
(CPU/RAM/GPU/سعر)، مقارنة بين حتى 3 أجهزة، سلة تسوق، مفضّلة (Wishlist)، تسجيل دخول/حساب،
checkout حقيقي مع تحديث المخزون تلقائياً، ولوحة تحكم Django Admin مخصصة.

## المزايا

- **صفحة رئيسية**: عروض، أجهزة مميزة، وصول جديدة، تصنيفات حسب الاستخدام (Gaming/Business/Student/Creator/Ultrabook)
- **صفحة المتجر**: فلاتر (Brand, Category, نطاق سعر, RAM, نوع التخزين, متوفر بالمخزون) + ترتيب
- **صفحة المنتج**: جدول مواصفات كامل، تقييمات ومراجعات، صور متعددة، إضافة للسلة/المفضلة/المقارنة
- **المقارنة**: جدول side-by-side لغاية 3 لابتوبات بكل المواصفات
- **السلة**: مبنية على الـ session (بدون حاجة تسجيل دخول للتصفح)
- **Checkout**: يتطلب تسجيل دخول، ينشئ Order + OrderItems، وينقص المخزون تلقائياً
- **حساب المستخدم**: تسجيل / دخول / خروج، سجل الطلبات
- **Admin panel**: إدارة كاملة للمنتجات، الطلبات، التقييمات مع فلاتر وبحث

## التصميم

هوية بصرية باسم "NOTEBIT" — خلفية رمادي فاتح (ألمنيوم)، accent برتقالي نحاسي، خط Space Grotesk
للعناوين وJetBrains Mono لعرض بيانات المواصفات (زي spec sheet حقيقي).

## التشغيل محلياً

```bash
# 1. إنشاء بيئة افتراضية
python -m venv .venv
source .venv/bin/activate   # على ويندوز: .venv\Scripts\activate

# 2. تثبيت المتطلبات
pip install -r requirements.txt

# 3. تطبيق الـ migrations
python manage.py migrate

# 4. إنشاء حساب أدمن
python manage.py createsuperuser

# 5. تشغيل السيرفر
python manage.py runserver
```

افتح المتصفح على `http://127.0.0.1:8000/`

### إدارة الموقع

بعد إنشاء حساب المدير، افتح `http://127.0.0.1:8000/admin/` أو سجّل الدخول بالحساب الإداري
ثم انتقل إلى لوحة التحكم من شريط التنقل. لا توجد بيانات دخول افتراضية محفوظة في المستودع.

## البيانات التجريبية

ملف قاعدة البيانات المحلي (`db.sqlite3`) وملفات الوسائط مخصّصة للتطوير فقط ومُستثناة من Git.
بعد تنفيذ `migrate` يمكنك إضافة منتجاتك من لوحة التحكم.

لإضافة صور حقيقية للمنتجات: ادخل على `/admin/store/laptop/`، افتح أي منتج، وارفع صورة بحقل
`image` (و`image_2`, `image_3` للمعرض).

## البنية

```
laptop_store/
├── laptop_store/       # إعدادات المشروع (settings, urls)
├── store/               # التطبيق الرئيسي: models, views, cart, admin
├── accounts/             # تسجيل الدخول / الحساب
├── templates/            # كل الـ HTML templates
├── static/css/style.css  # التصميم الكامل (design tokens + كل الصفحات)
├── media/                # صور المنتجات المرفوعة (تتولد تلقائياً)
└── db.sqlite3            # قاعدة بيانات محلية (غير مرفوعة إلى Git)
```

## خطوات لاحقة مقترحة (production)

- ربط بوابة دفع حقيقية (Stripe) بدل الطلب اليدوي
- نقل قاعدة البيانات من SQLite لـ PostgreSQL
- تفعيل `DEBUG = False` وضبط `ALLOWED_HOSTS` قبل النشر
- إضافة `django-storages` لو بدك ترفع الصور على S3/Cloud بدل السيرفر المحلي
